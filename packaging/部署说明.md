# 能源可信数据空间平台 · 离线安装包用户手册

> 本包为**完全离线**的一键安装包，目标机无需 Docker、无需网络。
> 两个产物：`energy-tds-v1.0-linux-x86_64.tar.gz`（x86_64 服务器 / 笔记本）与 `energy-tds-v1.0-linux-arm64.tar.gz`（树莓派 4B，64 位系统）。

## 1. 目标机要求

| 项 | x86_64 包 | arm64 包（树莓派 4B） |
|---|---|---|
| 系统 | 任意 systemd 发行版（Ubuntu 20.04+ / Debian 11+ / CentOS 7.9+ 等） | **Raspberry Pi OS 64-bit**（`uname -m` 必须为 `aarch64`；`armv7l` 须重刷系统） |
| 内存 | ≥ 3.5GB | 4GB 机型（安装程序会把 swap 调到 2GB） |
| 磁盘 | ≥ 8GB 空闲 | ≥ 8GB，**强烈建议 USB SSD** 而非 SD 卡 |
| 端口 | 80 空闲（可用 `--port` 改） | 同左 |
| 权限 | root（`sudo`） | 同左 |

## 2. 安装

```bash
# 1) 校验完整性（可选）
sha256sum -c energy-tds-v1.0-linux-x86_64.tar.gz.sha256
# 2) 解压并安装
tar -xzf energy-tds-v1.0-linux-x86_64.tar.gz
cd energy-tds-v1.0-linux-x86_64
sudo ./install.sh              # 可选：--port 8080  --no-kiosk  --no-start
```

安装程序依次执行九步（root 检查 → 架构校验 → 内存/磁盘 → 离线装 Docker → 端口检测 → 导入镜像并校验 SHA → 生成随机密钥 `.env` → 启动并等待健康检查 ≤180s → 注册 systemd 开机自启），成功后打印：

```

════════════════════════════════════════════
  访问地址   http://192.168.1.100

             grid / grid123          电网调度方
             vpp / vpp123            虚拟电厂运营商
```

首次安装在树莓派上通常 2~4 分钟（MySQL 初始化种子数据最慢）。

## 3. 安装后目录

```
/opt/energy-tds/
├── docker-compose.yml     # 已改为使用包内镜像，不含 build
├── .env                   # 随机生成的 MYSQL_ROOT_PASSWORD / MYSQL_PASSWORD / JWT_SECRET（权限 600）
├── config/mysql.cnf       # x86 标准版 / ARM 低内存版
├── sql/                   # 建表与种子脚本（首次启动自动执行）
├── kiosk.sh               # 仅 arm64 且启用 kiosk：等健康检查后全屏拉起 Chromium
├── uninstall.sh
└── VERSION
```

数据卷：`energy-tds-mysql-data`、`energy-tds-redis-data`（`docker volume ls`）。

## 4. 日常运维

```bash
systemctl status energy-tds                       # 服务状态（开机自启已启用）
systemctl restart energy-tds                      # 重启全部容器
cd /opt/energy-tds && docker compose ps           # 查看各容器健康状态
cd /opt/energy-tds && docker compose logs -f backend
cat /opt/energy-tds/VERSION                       # 版本、架构、构建时间、各镜像 SHA256
```

修改端口：编辑 `/opt/energy-tds/.env` 的 `FRONTEND_PORT`，然后 `systemctl restart energy-tds`。

## 5. 树莓派 Kiosk 全屏

arm64 包在检测到 `chromium`/`chromium-browser` 时自动安装 `energy-tds-kiosk.service`（以 `sudo` 前的桌面用户运行）。还需：

1. `sudo raspi-config` → System Options → Boot / Auto Login → **Desktop Autologin**
2. 禁用屏保：`/etc/lightdm/lightdm.conf` 的 `[Seat:*]` 下加 `xserver-command=X -s 0 -dpms`
3. `sudo reboot`，开机后 `/opt/energy-tds/kiosk.sh` 等 `/api/v1/health` 通过（最长 5 分钟）即自动全屏打开 `http://localhost`；日志：`journalctl -u energy-tds-kiosk -f`

手动控制：`systemctl start|stop energy-tds-kiosk`。不需要全屏可安装时加 `--no-kiosk`。

## 6. 升级 / 重装

重新解压新包并 `sudo ./install.sh` 即可：安装程序会先停旧实例、导入新镜像，**保留原 `.env` 与数据卷**（数据库密码不变，数据不丢）。如需全新初始化：`sudo /opt/energy-tds/uninstall.sh --purge` 后再安装。

## 7. 卸载

```bash
sudo /opt/energy-tds/uninstall.sh            # 停服务、删容器与镜像、删 systemd 单元；保留数据卷与 .env
sudo /opt/energy-tds/uninstall.sh --purge    # 连同数据卷、.env、/opt/energy-tds 一起删除（不可恢复）
```

卸载不会移除 Docker 本身。

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| `检测到 32 位 ARM 系统 (armv7l)` | 用 Raspberry Pi Imager 重刷 **Raspberry Pi OS (64-bit)**；硬件须为 3B+/4B/5 |
| `本包为 arm64，当前机器为 x86_64` | 换用对应架构的 tar.gz |
| `内存不足` | 树莓派需 4GB 及以上机型；x86 虚拟机请分配 ≥ 4GB |
| `端口 80 已被占用` | 脚本会列出占用进程；停掉它或 `sudo ./install.sh --port 8080` |
| `镜像文件校验失败` | tar.gz 拷贝不完整，重新拷贝并先 `sha256sum -c *.sha256` |
| 等待 180s 未通过健康检查 | 树莓派 SD 卡首次建库可能更久：`curl localhost/api/v1/health` 再等几分钟；`docker compose ps` 看是否有 Exited；`free -m` 看内存 |
| Docker 离线安装后 `docker info` 失败 | `journalctl -u docker -n 50`；常见为内核缺 overlay2 / cgroup，需较新内核（≥ 4.x） |
| 页面能开但登录失败 | 数据库种子未导入完成，等 1 分钟；或查看 `docker compose logs mysql` |
| DeepSeek 解释显示 `source=cache` | 正常离线降级；如需在线：编辑 `.env` 填 `DEEPSEEK_API_KEY`，`systemctl restart energy-tds` |
| 重装后 backend 连不上数据库 | `.env` 被手动删除导致密码与旧数据卷不一致：`uninstall.sh --purge` 后重装 |
| 树莓派整体卡顿 | 使用 USB SSD；确认 `config/mysql.cnf` 为 ARM 低配版；关闭不必要的桌面程序 |
