# 树莓派终端演示系统需求规格说明书

**项目名称：** 智慧配电网新型能源主体数据安全共享与隐私调度技术研究及应用  
**文档版本：** V1.0  
**编制日期：** 2026年3月  

---

## 一、系统概述

### 1.1 项目背景

本项目聚焦于智慧配电网中新型能源主体（如虚拟电厂、光伏、储能等）的数据安全共享与隐私调度技术研究。核心技术包括：
- 新型能源主体多维度数据分类分级与动态风险评估
- 基于 Top-k 梯度稀疏化与差分隐私的联合保护机制
- 云边协同联邦学习架构下的调度指令下发与终端响应

### 1.2 系统定位

| 项目 | 说明 |
|------|------|
| **系统名称** | 智慧配电网隐私调度中枢 |
| **系统角色** | 虚拟电厂云边协同全景沙盘（集成云端与边端双视角） |
| **运行环境** | 树莓派 4B（4GB RAM及以上）+ 7寸及以上电容触摸屏 |
| **运行方式** | 纯离线单机运行，无真实后台算法，全前端Mock数据动画展示 |
| **交互方式** | 纯模块化点击触发，支持设备选择、状态下钻与日志追溯 |
| **展示方式** | 树莓派连接触摸屏，全屏Kiosk模式展示 |

### 1.3 演示目标

通过树莓派模拟一个虚拟电厂终端节点（边缘侧）与调度中心（云端侧）的交互。在答辩现场，通过一套"带云边视角切换的模块化控制台"，直观展示"数据不出域"前提下的隐私保护与高效调度过程。

## 六、功能模块详细需求

### 6.1 模块1：全网设备状态图（云端专属）

#### 功能描述
展示全网边缘节点的实时状态拓扑图，支持点击节点查看详情并下发协同任务。

#### 界面元素

| 元素 | 说明 |
|------|------|
| 拓扑图 | 星型拓扑结构，中心为云端，四周为边缘节点（Node-A/B/C） |
| 节点标签 | 悬浮显示：在线状态 + 负荷数据（如：`在线 | 负荷: 120kW`） |
| 详情面板 | 右侧滑出抽屉，显示节点详情（设备型号、当前光储出力） |
| 操作按钮 | "下发协同任务"按钮 |

#### 交互流程

1. 页面加载后展示动态拓扑图
2. 点击节点 → 右侧滑出详情面板
3. 点击"下发协同任务"按钮 → 触发光波数据流动画
4. 底部日志栏输出对应日志

#### 日志输出

```
[CLOUD] 锁定目标节点 Node-A，启动虚拟电厂全局资源聚合任务 (Task_ID: VPP-R25)...
```

### 6.4 模块4：边缘隐私保护计算（边端专属）

#### 功能描述
展示核心隐私保护算法执行过程，包括数据脱敏、差分隐私加噪、梯度压缩。

#### 界面元素

| 元素 | 说明 |
|------|------|
| 数据对比区 | 左右对比展示处理前后数据 |
| 匿名化展示 | L3数据值变为 `*** 已匿名/脱敏 ***` |
| 加噪动画 | 数值跳动变化（如：32.1 → 32.38） |
| 矩阵动画 | Top-k稀疏化，接近0的数字变灰消失 |

#### 处理流程

1. **L3数据匿名化**：位置信息脱敏处理
2. **L2数据加噪**：执行差分隐私加噪（ε=0.5）
3. **梯度压缩**：Top-k稀疏化，通信开销降低80%

#### 日志输出

```
[EDGE] 分配本地算力，执行 Top-k 压缩与高斯加噪... 本地安全参数就绪，准备上传。
```
