
一、修订说明
原项目联邦学习、差分隐私、梯度压缩、DQN 调度、DeepSeek 大模型对接、基础区块链链上交互、国密基础加密算法均已完成自有代码开发与工程封装，本次外包开发不重复重构已有算法链路，核心工作聚焦新增DID 身份管理、数据可信存证、权限控制中心、安全审计中心四大安全支撑模块，完成四大模块与现有后端、算法、链服务、国密工具的全链路打通，配套完成整合后全系统可运行安装包制作交付，原有存量算法仅做接口适配改造，不改动核心计算逻辑。
本项目后端统一采用 MySQL 8.0 作为持久化关系数据库，本次新增 DID 身份、权限控制、可信存证、安全审计四大模块所有业务数据表均新建于 MySQL；Redis 仅用于临时缓存，Fabric 联盟链仅存储哈希摘要不存放业务完整数据，该技术规范参照完整后端开发总方案技术栈定义。
二、四大新增模块分模块外包开发实施方案
（一）DID 身份管理模块开发方案
本模块基于现有国密 SM2/SM3 密码库拓展开发，统一管理平台全参与主体分布式数字身份，对接端侧 ESP32 设备、边缘树莓派节点、云端运营账号、第三方园区企业四类主体，不替换现有国密加密底层，仅新增身份签发、解析、可信核验全流程能力。
核心开发内容
1）DID 标识生成服务：基于 SM2 非对称密钥生成全局唯一 DID 标识符，支持设备 DID、用户 DID、机构 DID 三类身份模板，生成 DID 文档并完成链上基础备案；
2）身份生命周期管理：提供身份注册、密钥轮换、身份冻结、注销、挂失恢复全套接口，对接现有 MQTT 设备接入链路，设备上线自动校验 DID 合法性；
3）跨主体身份可信核验：封装 DID 解析、验签工具类，为联邦学习梯度上传、调度指令下发、数据查询接口前置身份校验拦截，拦截非法无 DID 节点接入；
4）存量系统适配改造：在现有端侧采集、边缘梯度上传、云端聚合微服务中新增 DID 鉴权拦截器，原有算法数据流无需改动，仅新增身份校验前置逻辑；
5）配套MySQL 8.0数据表设计：DID 身份主表、密钥轮换日志表、设备身份绑定关系表，与现有 MySQL 用户、设备业务表关联；临时身份验签缓存使用 Redis。
与存量算法联动规则
联邦学习节点接入前校验有效 DID，无合法 DID 节点直接拒绝梯度上传；DQN 调度指令下发携带签发者 DID 签名，边缘节点校验通过后方可执行调度动作。
（二）数据可信存证模块开发方案
依托现有 Fabric 联盟链底层 SDK 拓展，独立拆分专用存证微服务，复用现有链上哈希上链能力，新增结构化数据标准化存证、存证溯源、防篡改核验、批量上链能力，不改动原有梯度哈希存证逻辑，实现业务数据、身份操作、权限变更、审计日志四类数据独立存证通道。
核心开发内容
1）标准化存证模板引擎：针对设备采集原始数据、联邦梯度参数、调度策略、权限变更记录、DID 操作日志设计统一存证结构体，自动计算 SM3 摘要后上链，原始数据不上链仅存哈希；
2）批量异步存证服务：高并发场景下批量打包存证交易，降低链上交互开销，适配虚拟电厂多节点高频数据上传场景；
3）链上存证溯源查询接口：提供按时间、设备、DID 主体、数据类型多维度溯源检索，支持导出链上存证凭证用于合规校验；
4）存证完整性校验工具：输入本地数据自动计算哈希，与链上存证值比对，输出数据是否被篡改的校验结果；
5）存量链路对接：打通 DID 身份模块、权限模块、审计模块，四类模块产生的关键操作数据自动推送至存证服务完成上链留存。
与存量算法联动规则
原有联邦梯度哈希存证逻辑保留，新增业务操作独立存证分区，两类存证数据在联盟链分层隔离存储，互不干扰，共用同一链节点资源。
（三）权限控制中心模块开发方案
搭建统一集中式权限微服务，基于 RBAC 多角色权限模型，整合现有接口 Token 鉴权逻辑，对接 DID 身份体系，实现基于分布式身份的细粒度分级数据、算法、操作权限管控，改造现有系统分散鉴权逻辑，统一收敛至权限中心。
核心开发内容
1）RBAC 权限模型设计：主体（绑定 DID）- 角色 - 资源 - 操作四层权限架构，预设管理员、园区运营、设备运维、算法观测、只读访客五类基础角色，支持自定义角色配置，所有角色、授权、权限变更记录持久化存储至 MySQL，权限 Token 短期缓存至 Redis。；
2）细粒度资源权限管控：区分三类资源权限 —— 设备原始数据读取权限、联邦模型训练参数查看权限、DQN 调度指令下发权限、链上存证查询权限，可单独为 DID 主体分配；
3）统一鉴权网关：为后端所有微服务提供统一权限校验接口，原有业务接口移除分散鉴权代码，统一调用权限中心完成身份 + 权限双重校验；
4）权限授权流转服务：支持机构间临时授权、时效授权、数据共享授权，授权记录同步推送至可信存证模块上链；
5）权限变更管理：权限授予、回收、调整操作留痕，自动同步至安全审计中心生成审计事件。
与存量算法联动规则
DeepSeek 大模型分析接口配置独立只读权限，无调度下发权限；联邦学习聚合、DQN 调度核心算法操作仅超级管理员 DID 可解锁执行权限，普通主体仅可查看结果。
（四）安全审计中心模块开发方案
搭建全链路日志采集、存储、检索、风险告警一体化审计服务，统一采集 DID 操作、存证上链、权限变更、算法执行、设备数据交互全链路日志，对接其余三大模块与原有所有后端微服务，实现安全行为全程可追溯。
核心开发内容
1）全链路日志采集埋点适配：在 DID 签发注销、存证上链、权限授予回收、梯度上传、调度执行、大模型调用等关键节点自动采集审计日志，日志携带唯一 TraceID、操作主体 DID、操作时间、操作内容、风险等级；
2）日志分级存储与检索：区分普通操作日志、敏感高危操作日志，审计全量结构化日志按月分表存入 MySQL，高危日志永久留存 180 天，实时告警缓存使用 Redis。提供多条件组合检索、日志导出接口；
3）安全风险规则告警引擎：预设越权访问、异常 DID 登录、高频权限变更、批量数据导出、可疑梯度上传五类风险规则，触发后实时推送告警信息至前端；
4）审计报告自动生成：按日 / 周 / 月输出平台安全审计报告，汇总身份操作、权限变更、数据存证、风险事件统计数据，支持对接 DeepSeek 生成自然语言风险解读；
5）日志防篡改：审计日志摘要自动推送至可信存证模块上链，避免日志人为删除篡改。
与存量算法联动规则
联邦学习梯度投毒检测、DQN 异常调度、差分隐私预算超限等算法异常事件自动推送审计中心标记为高危日志，触发风险告警。
三、存量已有算法适配改造范围（仅接口适配，无核心逻辑重构）
原有完整开发的算法包仅做轻量化适配对接四大新增模块，不改动算法计算核心，改造工作量远低于全新开发：
联邦学习、差分隐私、Top-k 梯度压缩：新增 DID 身份前置校验、梯度操作审计日志埋点、梯度存证推送逻辑；
DQN 隐私感知调度：新增调度指令签发 DID 验签、调度操作权限校验、调度记录自动存证、调度行为审计埋点；
DeepSeek 对接网关：新增模型访问权限管控、大模型调用行为全量审计、分析结果存证上链；
基础区块链存证 SDK：复用现有链交互能力，仅对接新增数据可信存证模块做分层数据隔离；
国密 SM2/SM3/SM4 加密工具库：复用底层密码算法，拓展 DID 身份生成、身份验签工具类。
四、跨平台安装包整合开发调整方案
原有云端、树莓派边缘、ESP32 端侧三套安装包基础上，新增四大模块容器 / 固件组件，完成一体化整合打包，无需重新制作整套安装包，仅新增组件并配置自动启停联动：
云端 Linux 一键安装包：新增四大安全模块独立 Docker 容器，Docker Compose 脚本新增模块启停顺序，初始化脚本自动创建 DID 数据库、权限角色模板、审计日志存储分区、链上存证账户；离线镜像包补充四大模块依赖，原有算法、中间件镜像完整保留。初始化脚本自动创建四大模块对应的 MySQL 数据表、索引与分表规则，自动执行建表 SQL 脚本；
树莓派边缘安装包：边缘节点轻量化接入 DID 校验客户端、本地操作审计采集组件，不新增重型链服务，仅同步上传边缘审计日志至云端存证；
ESP32 端侧固件：固件内置轻量化 DID 验签工具、本地操作日志缓存，设备数据上传前完成 DID 签名，操作日志批量上报云端审计中心；
安装包验收标准不变，新增校验项：四大模块服务启动正常、身份鉴权 / 权限拦截 / 存证上链 / 审计日志全链路打通。
五、外包项目交付物调整说明
代码交付：保留原有全部存量算法、后端源码，新增四大模块完整微服务源码、模块间适配改造代码、存量算法适配补丁；
安装包交付：整合四大模块后的三套完整可运行离线安装包，配套模块启停、初始化脚本；
文档交付：新增《四大安全模块详细设计说明书》《DID / 存证 / 权限 / 审计模块接口文档》《存量算法适配改造说明》，原有算法、部署手册完整保留；
测试交付：新增四大模块独立功能测试用例、端边云全安全链路联调测试报告、权限越权 / 身份伪造安全测试报告。
