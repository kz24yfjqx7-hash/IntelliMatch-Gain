
系统开发需求书
一、项目概述
基于现有虚拟电厂隐私调度系统代码（已有前端系统），完成能源可信数据空间平台升级开发。系统由现有能源数据展示、联邦学习模拟、智能调度展示能力，升级为具备可信身份、数据可信存证、权限控制、隐私计算、智能调度、安全审计能力的能源可信数据空间平台。
二、总体建设目标
建设能源主体可信身份体系，实现用户、企业、设备、边缘节点的DID数字身份管理。
建设能源数据可信管理体系，实现数据登记、分类分级、授权管理、Hash存证和全过程追踪。
建设细粒度权限控制体系，实现基于身份、角色、数据敏感等级和业务场景的数据访问控制。
建设隐私计算能力，实现原始数据不出域情况下的多主体协同建模。
建设智能业务赋能能力，实现DQN智能调度和DeepSeek智能分析。
建设安全审计体系，实现业务过程可查询、可验证、可追溯。
三、后端功能开发需求
3.1 用户认证与权限基础服务
实现用户注册、修改、删除、查询。
支持账号密码登录，采用Token认证机制。
采用RBAC权限模型，实现角色权限管理。
角色包括系统管理员、电网调度方、虚拟电厂运营商、能源主体、监管方、边缘节点。
3.2 DID数字身份管理服务
实现能源主体、设备节点、边缘节点DID生成。
支持DID查询、身份认证、状态管理。
通过DID+公钥签名完成可信接入。
3.3 密钥管理服务
实现密钥生成、绑定、查询、更新、冻结、注销。
密钥用于DID认证、数据签名和接口认证。
采用ECC/RSA非对称密码机制。
3.4 能源数据资产管理服务
实现能源数据登记、分类分级、数据溯源。
管理光伏、风电、储能、负荷、调度数据。
记录数据来源DID、敏感等级、Hash摘要和授权状态。
3.5 权限控制服务
基于用户身份+DID身份+角色+数据等级+业务场景进行权限判断。
支持数据访问、模型调用、任务执行权限控制。
实现申请、审批、授权、访问流程。
3.6 区块链可信存证服务
实现数据接入、授权、联邦任务、模型版本、调度结果存证。
链上保存Hash、身份凭证、授权记录和日志。
不存储原始能源数据。
3.7 安全审计服务
记录用户、DID、操作、资源、时间、结果、Hash。
支持根据任务ID查询完整业务链路。
3.8 联邦学习服务
支持训练任务创建、节点加入、模型上传、参数聚合、模型发布。
采用FedAvg联邦学习、差分隐私和梯度压缩机制。
3.9 智能调度服务
实现虚拟电厂优化调度。
输入新能源预测、负荷、储能SOC、电价等数据。
采用DQN强化学习生成调度策略。
3.10 AI智能分析服务
调用DeepSeek实现调度解释、数据分析、风险分析和智能问答。
3.11 软硬件通信服务
建设目标
实现端侧设备、树莓派边缘节点、云端后端与前端平台之间的信息交互。
通信要求
端侧设备通过 Modbus、RS485 或 MQTT 采集能源运行数据； 
端侧与边缘节点采用 MQTT + TLS 1.3 传输加密后的模型梯度、统计特征及设备状态； 
边缘节点通过 MQTT 或 HTTPS RESTful API 向云端上传压缩梯度，并接收全局模型和调度指令； 
前端与后端通过 HTTPS接口进行业务交互，通过 WebSocket 实时获取节点状态、调度进度和预警信息； 
网络中断时，边缘节点应支持数据本地缓存，并在网络恢复后继续上传。
3.12 API接口与系统联调要求
系统采用前后端分离架构。前端通过RESTful API调用后端业务服务，通过WebSocket接收节点状态、训练进度、调度结果及预警信息。端侧与边缘节点采用MQTT+TLS 1.3进行安全通信，边缘节点通过MQTT或RESTful API与云端交换模型参数、任务状态和调度指令。后端应提供统一API网关，并完成权限校验、业务服务及算法服务接口封装。外包方需提供完整接口文档及接口测试文件。

五、数据管理与系统部署要求
5.1 数据管理要求
建立统一数据管理能力，支撑身份管理、数据资产管理、权限控制、业务计算和安全审计。
管理用户、角色、DID、密钥关联信息。
管理能源数据资产、来源主体、数据等级、Hash摘要和使用记录。
管理权限申请、审批记录、业务任务、模型信息和审计日志。
采用关系型数据库并提供初始化脚本。
5.2 系统部署安装包要求
提供完整源代码、可运行程序、配置文件、启动脚本和部署文档。
提供前端程序、后端程序、数据库初始化文件。
提供Docker部署方式，支持一键启动前端、后端、数据库及相关服务。
支持离线运行。
提供演示安装包。
六、系统交付与验收要求
提供完整软件源码和部署说明书。
提供数据库初始化文件和演示账号。

满足快速部署要求。
