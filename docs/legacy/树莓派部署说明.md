# 树莓派部署说明

## 一、环境准备

### 1.1 硬件要求

| 硬件 | 规格 |
|------|------|
| 树莓派 | 4B（4GB RAM及以上） |
| 存储卡 | 32GB MicroSD卡（Class 10） |
| 显示屏 | 7寸及以上电容触摸屏 |
| 电源 | 5V/3A USB-C电源适配器 |

### 1.2 软件要求

| 软件 | 版本 |
|------|------|
| 操作系统 | Raspberry Pi OS（推荐64位桌面版） |
| Node.js | v20.x 及以上（LTS版本） |
| npm | v10.x 及以上 |

> **注意**：以下命令中的 `<用户名>` 请替换为您的实际用户名（可通过 `whoami` 命令查看），默认为 `pi`。

---

## 二、系统安装

### 2.1 安装 Raspberry Pi OS

1. 下载 **Raspberry Pi Imager**：https://www.raspberrypi.com/software/
2. 插入 MicroSD 卡到电脑
3. 运行 Raspberry Pi Imager
4. 选择系统：**Raspberry Pi OS (64-bit)**
5. 选择存储卡，点击"写入"
6. 写入完成后，将卡插入树莓派并启动

### 2.2 初始配置

首次启动后，执行以下配置：

```bash
# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装 Node.js 20.x（LTS版本）
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# 验证安装
node -v
npm -v
```

---

## 三、项目部署

### 3.1 上传项目文件

**方式一：通过U盘拷贝**
1. 将整个 `raspi` 文件夹拷贝到U盘
2. U盘插入树莓派
3. 复制到 `/home/<用户名>/` 目录

**方式二：通过SCP传输**
```bash
# 在开发电脑上执行
scp -r raspi <用户名>@<树莓派IP>:/home/<用户名>/
```

### 3.2 安装依赖

```bash
cd /home/<用户名>/raspi
npm install
```

如果遇到权限问题，执行：

```bash
chmod -R +x node_modules/.bin
```

### 3.3 构建生产版本

```bash
npm run build
```

构建完成后，生成 `dist` 目录。

### 3.4 安装静态服务器

```bash
sudo npm install -g serve
```

### 3.5 测试运行

```bash
serve -s dist -p 3000
```

打开浏览器访问 `http://localhost:3000` 验证是否正常运行。

## 四、开机自启动配置

### 4.1 创建启动脚本

```bash
nano /home/<用户名>/start-demo.sh
```

写入以下内容：

```bash
#!/bin/bash
cd /home/<用户名>/raspi
serve -s dist -p 3000
```

保存后添加执行权限：

```bash
chmod +x /home/<用户名>/start-demo.sh
```

### 4.2 配置 systemd 服务

```bash
sudo nano /etc/systemd/system/demo.service
```

写入以下内容：

```ini
[Unit]
Description=Smart Grid Demo System
After=network.target

[Service]
Type=simple
User=<用户名>
ExecStart=/home/<用户名>/start-demo.sh
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target
```

### 4.3 启用服务

```bash
sudo systemctl daemon-reload
sudo systemctl enable demo.service
sudo systemctl start demo.service
```

### 4.4 验证服务状态

```bash
sudo systemctl status demo.service
```

## 五、全屏 Kiosk 模式配置

### 5.1 安装 Chromium 浏览器

```bash
sudo apt install -y chromium
```

> 注意：新版 Raspberry Pi OS 可能已预装 Chromium，可通过 `which chromium` 检查。

### 5.2 配置自动登录

```bash
sudo raspi-config
```

选择：`System Options` → `Boot / Auto Login` → `Desktop Autologin`

### 5.3 配置开机启动浏览器

编辑自动启动文件：

```bash
mkdir -p /home/<用户名>/.config/autostart
nano /home/<用户名>/.config/autostart/demo.desktop
```

写入以下内容：

```ini
[Desktop Entry]
Type=Application
Name=Smart Grid Demo
Exec=chromium --kiosk --disable-restore-session-state --noerrdialogs --disable-infobars --no-first-run --enable-features=OverlayScrollbar http://localhost:3000
Terminal=false
Hidden=false
```

### 5.4 禁用屏幕保护

```bash
sudo nano /etc/lightdm/lightdm.conf
```

在 `[SeatDefaults]` 下添加：

```ini
xserver-command=X -s 0 -dpms
```

### 5.5 重启验证

```bash
sudo reboot
```

重启后系统将自动进入全屏演示模式。

## 七、常见问题

### 7.1 apt 锁冲突

```bash
# 停止 packagekit 服务
sudo systemctl stop packagekit
sudo systemctl disable packagekit

# 然后重新执行 apt 命令
sudo apt update
```

### 7.2 npm run build 权限问题

```bash
chmod -R +x node_modules/.bin
npm run build
```

### 7.3 端口被占用

```bash
# 查看端口占用
sudo lsof -i :3000

# 结束占用进程
sudo kill -9 <PID>
```

### 7.4 服务无法启动

```bash
# 查看服务日志
sudo journalctl -u demo.service -f

# 重启服务
sudo systemctl restart demo.service
```

### 7.5 浏览器无法全屏

检查 `autostart` 配置文件路径是否正确：

```bash
ls -la /home/<用户名>/.config/autostart/
```

### 7.6 屏幕分辨率调整

```bash
sudo nano /boot/firmware/config.txt
```

添加或修改：

```ini
hdmi_group=2
hdmi_mode=87
hdmi_cvt=1024 600 60 3 0 0 0
hdmi_drive=1
```
